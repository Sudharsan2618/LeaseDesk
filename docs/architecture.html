Flow: user NL request → API → graph understand → per-step confirm gates (SSE streamed back to the UI) → assemble → run_pipeline → scenarios → workspace_gate → human_review → final_validation → generate_offer. State persists to the checkpoint (resume) and the normalized tables (query); every step appends to audit_events.
